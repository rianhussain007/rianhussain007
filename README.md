## What I'm Building

### 🦺 ErgoVigilance

**AI-powered industrial ergonomics & workplace safety**

A computer-vision system designed to understand worker posture and identify ergonomic risks in real time.

**Built with:**
`Python` `FastAPI` `React` `TypeScript` `MediaPipe` `YOLO` `WebSockets`

**What makes it interesting:**

* 🎥 Real-time human pose & person detection
* 📊 RULA / REBA biomechanical risk scoring
* 🧠 Task classification & forecasting
* ⚡ Live monitoring and alerts
* 📄 Automated reporting
* 🏭 Designed around real industrial workflows

🔗 **[Explore ErgoVigilance →](https://github.com/rianhussain007/Ergovigilance-)**

### MarmaAI

**AI-powered acupressure point localization & AR guidance**

A computer-vision system for locating and verifying hand acupressure points and guiding users through precise interactions.

**Built with:**
`Python` `OpenCV` `MediaPipe Hands` `Next.js` `Machine Learning`

**Highlights:**

* 🎯 21-point acupoint dictionary
* 🖐️ Real-time hand landmark detection
* 🥽 AR guidance & overlays
* 🎚️ Per-user calibration
* ✅ Automated execution verification
* 📈 Evaluation & batch-processing pipelines
* 🧪 Dataset collection and experimentation tooling

🔗 **[Explore MarmaAI →](https://github.com/MarmaAI/Backend-logic)**
